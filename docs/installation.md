# Installation

## Prerequisites

- Python 3.13+
- Poetry (optional, for development)

## Install from PyPI

```shell
pip install defectdojo-cli2
```

## Install from source

```shell
# Clone the repository
git clone https://github.com/DefectDojo/defectdojo-cli.git
cd defectdojo-cli

# Install dependencies
poetry install

# Or using pip
pip install -e .
```

## Verify Installation

```shell
defectdojo --version
```
